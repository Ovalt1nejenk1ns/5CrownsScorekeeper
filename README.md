# Five Crowns Scorekeeper

A phone-friendly scorekeeper for Five Crowns: 11 rounds (3 cards up to 13), the wild card shown each round, the dealer rotated for you, and lowest total wins.

- **Play:** https://ovalt1nejenk1ns.github.io/5CrownsScorekeeper/
- **At home:** served by the Game Night server on klisby, where every game is saved to SQLite and a "← Game Night home" link appears.
- **Rules:** `tutorial.html` is the full how-to-play guide.

Games left by the old version of this page (an in-progress game and past games) are carried over automatically.

Plain HTML, CSS and JavaScript — no build step.
